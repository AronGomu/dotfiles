- C3. **Origin URL unset. Authoritative bootstrap branch unset. Remote ownership/visibility/downstream effects unset.** Current local initial branch: `bootstrap/dotfiles`. Never invent URL or infer authorization from existing Git identity. Repo checkout row uses `-` until user supplies remote.
- C4. Initial bootstrap exception: expressly authorized creation may proceed without configured remote. Initial export was prepared unstaged, uncommitted for parent/user review. Inspect Git for current state; stage/commit only when authorized, independently of publication approval. Do not block source preservation on missing origin. Do not claim clean/synchronized completion. Before first publication, user supplies URL, bootstrap branch, permissions, visibility, downstream effect/recovery contract.
- C5. Later work defaults to feature branch. No direct main/master push unless authorized, no PR unless requested, no history rewrite. Reversible validated in-scope config sync to configured authorized remote/branch needs no per-push confirmation. Irreversible/unknown effects still require stop. Feature-only delivery ≠ bootstrap branch synchronized.
- C6. Full sync proof: whole worktree clean including untracked files, no staged diff, fetched approved bootstrap remote tip equals local HEAD, ahead/behind `0 0`. Preserve unrelated dirt; no reset/stash/discard/mass-stage. Scanner findings/missing auth/divergence block publication, never justify unsafe cleanup.
